# Claude Learnings

Two guides for getting set up with the Claude Code CLI — covering plugins, skills, memory, hooks, subagents, MCP servers, and the full feature-development flow.

## Pick a guide

| Guide | When to read | Time |
|---|---|---|
| **[Quick Start](./quick-start.md)** | You've only used Claude in VS Code. Install, enable 5 plugins, learn 5 commands. | 5 min |
| **[Full Guide](./full-guide.md)** | You've done the quick start and want depth: skills, hooks, subagents, MCP, end-to-end flow, and **when to use Opus vs Sonnet vs Haiku**. | 30 min |

**Suggested path:** do the Quick Start, build something for a day, then come back for the Full Guide.

## What's in here

- `quick-start.md` — 4-step setup + the 5-command Day-1 workflow + 3 habits that matter
- `full-guide.md` — mental model, plugins, skills, end-to-end flow (brainstorm → plan → execute → verify → review → ship → wrap-up), memory system, hooks, subagents, MCP servers, model routing (Opus/Sonnet/Haiku), slash command cheat-sheet, and common pitfalls
